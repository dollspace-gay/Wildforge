# Working in mods

Read [README.md](README.md) and [the root instructions](../AGENTS.md).

The existing README is an executable authoring reference. gems is the checked-in example pack; other installed directories can be ignored local content. Registry loading and signed world identity depend on stable mod names and data.

Preserve the existing README bytes during architecture work because historical documents contribute to content identity. New README.md and AGENTS.md guides must begin with the wildforge:guide HTML comment. Only these marked guide names opt out; TOML, images, and other data remain content. Never modify installed third-party mods as part of directory documentation.

Run the focused registry and content-identity tests from the root, then the applicable full gates. Provide both local guides for new maintained subdirectories.
