# Working on native qualification

Read the local README and parent instructions. Keep process execution, matrix
planning, metrics, and publication separate. Never relabel an older frame as a
new capture, change acceptance thresholds to fit a run, or suppress failed
attempts. Record source and executable hashes, clean revisions, exact inputs,
and actual GPU identity. Use isolated saves and target only processes started
by the campaign. Keep modules around 400 lines. Test parsing/provenance failures
and rerun affected native scenarios before accepting changes.
