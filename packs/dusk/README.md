# Dusk palette

pack.toml describes the cool moonlit overworld palette. tiles contains its PNG overrides, loaded through the common texture-pack resolver.

Preserve the pack identity and override naming. Palette adjustments need side-by-side daylight and night captures so block readability and transparency remain useful.

Run `cargo test --locked tests::rendering::` from the repository root. See [AGENTS.md](AGENTS.md) for working instructions.
