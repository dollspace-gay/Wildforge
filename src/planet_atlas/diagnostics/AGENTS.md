# Working in diagnostics

Read [README.md](README.md) and [the parent guidance](../AGENTS.md).
Preserve deterministic traversal, selection ties, stable IDs, units, field
order, artifact names, and observed evidence. Diagnostics must read actual
state and distinguish estimates from measurements. Do not weaken qualification
criteria or fabricate a location when no candidate exists. Use explicit imports
and cohesive modules around 400 lines; review above 500. Run focused diagnostic
scenarios and applicable full gates before acceptance; record incomplete work.
