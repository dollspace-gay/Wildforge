# Atlas diagnostics

The parent validates and coordinates exports. Census cells and sparse records
have separate collectors; report schemas and CSV projection are explicit. Maps
read registered values and use shared image encoding. Climate/river transects,
weather examples, country routes, and memory estimates retain their own inputs.
`catalog/` preserves map order; `sites/` selects reproducible scenario coordinates.

Read [AGENTS.md](AGENTS.md). Final checks compare map/legend/report output,
registered order, census totals, site selection and coordinates, and the
applicable atlas/runtime qualification evidence on the final source.
