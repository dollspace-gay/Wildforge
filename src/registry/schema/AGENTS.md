# Working in raw content schemas

Read [README.md](README.md) and [the registry guidance](../AGENTS.md).
Keep deserialization separate from name/ID linking and publication. Preserve
field names and defaults in structural moves, including legacy alternatives.
Do not add simulation, I/O, rendering, or runtime state ownership here.
Keep imports explicit, target 400 lines, and review any file above 500.
