# Common authoritative spawn

Atlas selection receives immutable atlas summaries; voxel qualification receives
prepared immutable chunks. Their typed candidate, diagnostics and verification
results remain defined in the parent. They do not schedule workers or mutate a
live world. Candidate scoring, tie order and bounded portfolio order are unchanged.

The entry coordinator owns manifest validation, cancellable trials, sorted
adoption, final save/digest publication and prepared-position rescue. Discovery
site census and saved-ledger verification retain named stages. Once durable
adoption begins, finish its save sequence before reporting cancellation. Every
trial worker remains owned/joined by the existing preparation module.

See [world transaction order](../transaction-order.md) for cross-domain fan-out.
Run world/generation/streaming, save compatibility and conservation tests, then
the root Rust gates and final native/GPU qualification from the repository root.
