# Calendar and environment coordination

CalendarState and WeatherState own time and live weather. The clock-access and
observation adapters expose their existing interfaces. Weather admission/stepping
and loaded-water spring/shore reconciliation are separate coordinators.

Seasons/Long Winter, regional and global ire, industrial pressure, reciprocity,
offerings/depots, lightning and renewable growth keep their separate rules and
original call order. Calendar queries do not advance simulation. Seasonal and
weather constants remain compatible with existing saves and day length.

See [world transaction order](../transaction-order.md) for cross-domain fan-out.
Run world/generation/streaming, save compatibility and conservation tests, then
the root Rust gates and final native/GPU qualification from the repository root.
