# Authoritative implements integration

The frame dispatcher chooses existing named actions. Layout and conductor walks
observe physical apparatus; assembly, calibration, charm binding, transfer,
discharge, disassembly, focus swap, repair, and break each own one transaction
coordinator. Ambient custody, legacy migration, vessel ticking, failure, and
retirement retain their separate admission and recovery boundaries.

The existing implement state and Current/material ledgers still own identity,
charge and conservation. Coordinators preserve preflight, cloned next-state,
linked journal commit, physical application and save order. Parent helpers share
bounded neighborhood rules and the existing account-map transaction builder.

These modules coordinate cross-domain transactions; moving a method here does
not make it an independent simulation owner. Public World entry points and save
formats are preserved. Run the applicable world, implements, conservation, replay,
and multiplayer parity tests followed by the root Rust/native gates.
