# Physical discovery integration

Experiment slots, artifact custody, tuning lenses, observations and catalogue
operations have named coordinators. The parent defines observation targets and
pure qualitative bands/uncertainty helpers. Discovery state remains the owner of
records and recovery markers, with persistence and physical custody explicit.

Observation output must retain qualitative uncertainty and calibrated access;
structural moves cannot expose exact private ledger values to a guest.

Run the applicable world/machine, sidecar compatibility, conservation and replay
tests, then root Rust gates and final native evidence from the repository root.
