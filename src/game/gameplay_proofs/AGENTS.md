# Working in native client proofs

Read [README.md](README.md) and [the graphical client guidance](../AGENTS.md).

Require the real hardware adapter and preserve the ordinary guest admission,
input, replication, and shutdown paths. Reuse the owned host fixture. Keep
failures visible, waits bounded, and fixture worlds separate from user saves.
Capture actual renderer output and record its build and adapter identity.
Functional screenshots do not replace production visual/performance gates.
