# Working in contextual interactions

Read [README.md](README.md) and [the parent guidance](../AGENTS.md).
Keep UI request selection and physical transaction authority distinct. Do not
make a guest borrow local World to complete a predicted interaction. Preserve
signed record/holder identities and use existing shared domain transactions.

Do not reorder short-circuit choices in contextual alchemy or physical target
selection; the first eligible choice is the visible gameplay contract. Keep
actual script, input, and transport paths in native proofs. Aim for 400 lines,
review above 500, and run the repository Rust gates and gameplay proofs after
the authorized implementation phase.
