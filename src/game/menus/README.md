# Menu transitions

The parent menu_click has one exhaustive screen match. Screen-family handlers
perform existing hit tests and navigation/action calls; each early return ends
that click without affecting later frames. Layout stays shared with drawing.
Account linking/revocation retains one owned asynchronous task and its existing
poll/publication/error path. No selector changes the user's disclosure choice.

Run applicable UI/session/inventory characterization and parity tests, then the
root Rust gates and final native gameplay/GPU proofs from the repository root.
