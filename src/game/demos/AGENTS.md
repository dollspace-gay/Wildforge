# Working in capture fixtures

Read [README.md](README.md), the parent game guide, and root AGENTS.
Keep environment selectors, call order, positions, material/item custody, camera
framing, and persistence unchanged during structural moves. Use canonical chart
conversion and real authority operations; decorative stand-ins do not qualify
physical gameplay. Do not invoke these authority-only fixtures for a guest.
Keep each scene family cohesive and review files above 500 lines.
Validate changes with the final native and actual GPU qualification campaigns;
record source/binary provenance and never reuse old captures as current evidence.
