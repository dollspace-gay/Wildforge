# Capture scene fixtures

These opt-in development scenes construct real authority state for GPU and native
qualification. The parent coordinator retains the original environment-variable
order: early presentation overrides, physical scenes, calendar/weather overrides,
late scenes, and the implement/alchemy/planet fixtures. Multiple flags may coexist,
so moving calls or deduplicating overrides can change the resulting fixture.

Modules group lighting/materials, ecology/animals, industry/trade/storage, flow,
and planet landmarks. DemoChart and the existing authored-scene macros centralize
canonical coordinates and material accounting; ordinary entry never invokes a
fixture body without its selector. The alchemy and implement scenes use real
station verbs and preserve item identity and save ordering.

The lava setup's missing-content exit still stops subsequent scene staging.
Review both selected and combined selectors in the final native GPU campaign.
Fixture changes need actual hardware captures and timing evidence, using the
commands and provenance requirements in the root README and qualification tools.
