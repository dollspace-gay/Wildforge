# Application commands

`mod.rs` selects one process command in the established precedence order. The
cracked-geode capture command is checked first. When no command matches, the
app launches the windowed client. Domain adapters own argument interpretation, progress,
printed diagnostics, and exit status. Game rules and persistence remain in
their engine owners.

`audits.rs` checks persisted ledgers; `geography.rs` inspects and exports arcane
geography or explicitly applies retrogen. `worlds.rs` creates worlds/atlases,
`entry.rs` prepares and audits common entry, and `qualification.rs` runs content
and magic reports. `launch.rs` enters dedicated or agent runtimes.

Run commands from the repository root. Final validation includes CLI precedence,
usage and failure statuses, disposable world/export fixtures, and the root Rust
gates. Read [AGENTS.md](AGENTS.md) before editing this area.
