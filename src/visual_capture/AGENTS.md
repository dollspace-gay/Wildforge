# Working on visual campaign identity

Read the local README and parent instructions. Keep evidence selection bounded
to repository-relative screenshot directories and reject incomplete provenance.
Fingerprint newly introduced source modules as well as existing files. Keep
capture generations separate; preserve the prior records when qualifying a
new build. Changes here require negative freshness/path tests, the full Rust
gates, and matching real GPU campaign evidence. Aim for 400-line modules.
